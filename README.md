# ⚡ Світло — iPhone PWA для мониторинга графиков ДТЭК Киев и Киевская область

🌐 **Рабочее приложение (GitHub Pages)**: [https://ukdc.github.io/dtek-svitlo-app/](https://ukdc.github.io/dtek-svitlo-app/)  
📋 **Полный план реализации и архитектура (для разработчиков и ИИ-моделей)**: [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)

Быстрое и удобное приложение для **iPhone (iOS 18.7+ PWA)** для отслеживания актуальных графиков отключений электроэнергии в Украине:
- **ДТЭК Киевские электросети (г. Киев)**: `https://www.dtek-kem.com.ua/ua/shutdowns` (`1.1` – `60.2`, 60 подгрупп)
- **ДТЭК Киевские региональные электросети (Киевская область)**: `https://www.dtek-krem.com.ua/ua/shutdowns` (`1.1` – `6.2`, 12 подгрупп)

## Возможности
- **Произвольные названия адресов**: добавляйте сколько угодно адресов и задавайте им собственные названия («Моя квартира», «Офис», «Родители», «Дача» и т.д.) и иконки.
- **Полный справочник улиц и населённых пунктов с выпадающими подсказками**:
  - **3 406 улиц г. Киева** (`state/kyiv-streets.json`) с автоопределением группы ДТЭК по номеру дома.
  - **1 038 населённых пунктов Киевской области** (`state/oblast-settlements.json`) + динамическая подгрузка улиц любого села/города через OpenStreetMap Overpass & Nominatim API (`CORS *`).
- **Тройной каскад оперативных источников данных**:
  1. `Baskerville42/outage-data-ua` (`kyiv.json` и `kyiv-region.json`) — обновление каждые 5 минут с поддержкой прямого чтения из браузера (`CORS *`).
  2. `YASNO Public API v2` (`app.yasno.ua`) — официальные слоты по Киеву, статус экстренных отключений и автоопределение группы по улице и номеру дома.
  3. Сайты `dtek-kem.com.ua` и `dtek-krem.com.ua`.
- **Только оперативные вкладки «Сегодня» и «Завтра»** (без таймера обратного отсчёта и без недельного прогноза): наглядная 24-часовая шкала с шагом 30 минут, карточки интервалов и индикация изменений графика в течение дня.
- **Push-уведомления на iPhone (iOS 18.7+)**:
  - За **~30 минут до начала отключения** (скользящее окно `[10..42]` мин с дедупликацией `notifiedEvents`).
  - За **~30 минут до включения света**.
  - Мгновенно при **изменении графика в течение дня**.
  - Поддержка **«Тихих ночных часов»** (`23:00 – 07:00`).

## Как установить на iPhone (iOS 18.7+)
1. Откройте [https://ukdc.github.io/dtek-svitlo-app/](https://ukdc.github.io/dtek-svitlo-app/) в браузере **Safari** на iPhone.
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“» (Add to Home Screen)**.
3. Откройте приложение с домашнего экрана, нажмите на иконку колокольчика 🔔 и включите **Push-уведомления**.

## Команды разработки и сервера
```bash
npm install
npm test             # Запуск unit-тестов нормализатора и триггеров уведомлений
npm run push:check   # Синхронизация свежих графиков ДТЭК/YASNO и отправка Web Push
npm run build        # Сборка production PWA бандла
npm start            # Запуск сервера (API + раздача PWA + фоновый опрос каждые 10 мин)
```
