# ⚡ Світло — графики отключений ДТЕК (Киев и Киевская область) с пушами на iPhone

🌐 **Приложение**: https://ukdc.github.io/dtek-svitlo-app/
🛠 **Для разработчиков и ИИ-агентов**: начните с [AGENTS.md](./AGENTS.md) → [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) (как устроено) и [docs/HISTORY.md](./docs/HISTORY.md) (журнал проблем).

PWA для iPhone (iOS 18.7+) и любого браузера:
- **Киев** (ДТЕК Київські електромережі, группы `1.1`–`60.2`) и **Киевская область** (ДТЕК Київські регіональні, `1.1`–`6.2`).
- Несколько адресов со своими названиями; **группа определяется по адресу автоматически** (Киев — за секунды, область — 20–90 с), ручной выбор — если не получилось.
- «Кільце доби»: часы-циферблат на текущие 12 часов + дорожка «что дальше», вкладки «Сьогодні» / «Завтра», список интервалов.
- **Push-уведомления**: ~за 30 мин до отключения, ~за 30 мин до включения, при изменении графика; тихие ночные часы.

Подписка на уведомления — по коду-приглашению (круг знакомых, не публичный сервис).

## Установка на iPhone
1. Откройте https://ukdc.github.io/dtek-svitlo-app/ в **Safari**.
2. «Поделиться» → **«На экран „Домой“»**.
3. Откройте приложение с домашнего экрана → колокольчик → «Сповіщення» → в «Додатково» введите код-приглашения → включите уведомления.

## Разработка
